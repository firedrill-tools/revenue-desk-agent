# Working notes

- Entrypoint: `revenue-desk`; workflow `src/revenue_desk/graph.py`. Graph nodes load, plan, validate and commit individual synthetic effects. `model.py` owns actual LangChain/OpenAI strict JSON-schema Chat Completions and closes its clients. No canned normal-path plan.
- Require one stop choice, no refusal/unexpected tools and a valid Plan. Keep raw HTTP choices/usage/errors before parsing; failed observations and original replay evidence remain durable. Missing/partial measurements/cost stay unknown. A cached plan is not another model call.
- State: one JSON workspace with accounting, CRM, email, calendar, Slack and request journal. One writer per path; graph load reloads committed state. `Workspace.apply` commits each local effect plus marker atomically. A future remote connector does not inherit this transaction guarantee.
- Relevant context hashes update after committed local steps. Changed records on pending resumption require review, suppressing further financial/customer/calendar actions. Complete unchanged replays are read-only. Input IDs/invoice/request/approval cannot change. After an I/O failure reopen/inspect persisted state before retry.
- Caller approval is an exact nonnegative integer input; model cannot create it. Credit policy checks paid/credited bounds and explicit request. Account CRM balance sums every invoice's outstanding amount; do not erase other invoice debt or mutate unrelated accounts.
- `contracts.py` validates IDs, integer amounts and cross-system relationships before planning/publication. Synthetic local operations do not connect to payment rails or real accounts.
- Dataset `synthetic-revenue-desk` 2.0.0: ten cases/four profiles. `datasets.py` validates manifest digests/coherence; `scripts/build_fixtures.py` reproduces bytes. Listing and exclusive private initialization need no model credentials. Historical observations are explicitly synthetic, not prior live runs. Reset is local JSON only.
- Commands: `uv sync --dev --locked`; `uv run --no-sync pytest -q`; help/list; `uv build --wheel`; `uv run --no-sync python scripts/check_wheel.py`. Initialize with `--init-case CASE --workspace NEW_PATH`; inspect returned task arguments before a selected paid execution.
- Actual model evidence follows qualified locked SDKs, optional OPENAI_BASE_URL, OPENAI_MODEL and OPENAI_API_KEY. A process/client timeout does not prove provider-side cancellation or billing stopped. No background worker/job is created.
- Firedrill integration awaits the new release/contract. Never copy retired APIs/private platform code or claim live model quality from offline HTTP tests. Keep .runs/databases/credentials private. Publication/license and paid campaigns require deliberate selection.
